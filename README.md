# SideQuest

SideQuest finds SFU students who are free when you are, then gives slightly unhinged side quests to do together to break the ice, so the first meetup is not awkward. 

## Run it

https://sidequest-app-nine-iota.vercel.app/

or

copy the git repo and

```bash
npm install
cp .env.example .env      # set EXPO_PUBLIC_API_URL to where the backend runs
npx expo start            # scan the QR code with Expo Go, or press i / a / w
```
